CONTEXT
  A12 covered C1/C2/C3/C5 and emitted H2/H3/H4 as PENDING_C4. A13 adds C4 -- the
  full agentic tool-loop (thesis eq 10.30-10.35): fine-tuned LLM + RAG + a
  deterministic loop that iterates on evaluator feedback over an EVOLVING working
  state x_t, versus C1/C2/C3 which apply every proposal to the frozen baseline x0
  independently. Reuses the A12 machinery unchanged (EqualBudgetLedger,
  apply_proposal, ParetoArchive, events, RunOutcome, 11.19 contract).

DECISIONS (user, LOCKED 2026-08-31 -- see design doc section 13)
    Select policy   : archive_guided_v1 -- deterministic, seeded, NO extra LLM
                      call (repair > explore/diversify > exploit corner). LLM-chosen
                      selection is a future extension.
    First backend   : C4_base -- Ollama llama3.1:8b + RAG + tools. Canonical C4
                      (fine-tuned C3 backend) swaps in with zero loop changes once
                      the C3 adapter defect (see A12 section) is fixed.
    Convergence     : L = 10 look-back, epsilon_hv = 0.1 absolute HV, variant
                      "delta". Frozen in run_config before any run; part of run_id.
    Retry cap K     : 3 per selection episode; then Select() moves to a different
                      part/intent. x_t never resets (bounded backtracking is a
                      v1-future extension, decision 7).
    Accept()        : feasible AND ParetoArchive.offer() status in
                      {pareto_improving, non_dominated}. The non_dominated class IS
                      the lateral move; no separate single-objective rule.
    H3 ablation scope: 3-seed pilot per variant; full 10 seeds only if the pilot
                      shows the expected ordering.

DEVIATIONS FROM THE THESIS TEXT (small, documented, not silent)

    eq 4.2 convergence test   -> stops on EITHER hv_plateau (max-min of HV over the
                                last L evals < epsilon_hv, AT ANY LEVEL INCLUDING 0)
